# [原创软件] EUI Linker Pro - 高颜值/现代化的目录硬链接/符号链接创建工具 (纯绿色便携版)

## 📌 软件简介
大家在平时使用电脑时，经常会遇到 C盘空间不足（比如微信、QQ缓存、C盘流氓软件数据），或者玩游戏打 Mod 时需要在不同目录同步文件的情况。这个时候，Windows 自带的 `mklink` (符号链接/目录联接) 就是神器！但自带的命令行使用门槛高，参数容易记错。

为此，我开发了这款 **EUI Linker Pro**。它完全基于极速先进的 **EUI-NEO C++ 图形框架** 构建，不仅拥有即点即开的极速启动性能，更利用现代 GPU 硬件加速技术，展现出了极其纯粹、顺滑的现代化拟物高颜值界面！只有区区几十兆的内存占用，小白也能一键搞定目录映射、C盘搬家等进阶操作！

## ✨ 核心特色功能
1. 🎨 **极致 EUI-NEO 渲染引擎**：告别臃肿的 Electron，基于纯 C++ 底层构建。深色模式优雅配色，动态流式布局，自适应各种分辨率和窗口大小，窗口随意拉伸排版依然严丝合缝。
2. 🚀 **双向链接引擎**：
   - **符号链接 (Symbolic Link /D)**：适用于常规文件/文件夹跨盘符的快捷映射。
   - **目录联接 (Junction /J)**：适用于大型游戏 Mod、C盘软件数据无损搬家（欺骗底层系统，让软件以为文件还在原处）。
3. 📁 **极简操作**：不需要懂任何命令行！只要一键选择“需要被链接的目标路径”和“生成的快捷链接路径”，点击执行即可。
4. 📜 **详尽的历史记录**：软件内置历史记录日志面板（支持超长路径自动换行），每一次执行结果是成功还是失败、目标路径在哪，一目了然！
5. 🍀 **100% 纯绿色单文件版**：绝不写注册表！绝不乱丢 AppData！历史日志 `mklink_history.tsv` 以及窗口记忆配置，都会自动跟随 `.exe` 生成在同一目录下。拷进 U盘即插即用！
6. 💡 **智能窗口记忆**：自动记忆上次关闭时的窗口位置与大小，下次打开无感还原，无残影，极致丝滑。

## 🛠️ 典型使用场景 (Why you need it?)
- 🧹 **C盘瘦身/微信数据搬家**：将 `C:\Users\用户名\Documents\WeChat Files` 剪切到 D 盘，然后用本软件将 D 盘的新目录【目录联接】回 C 盘原位置。C 盘瞬间腾出几十 G，且微信完全无感正常运行！
- 🎮 **游戏 Mod 整理**：很多大型单机游戏不支持在游戏目录外放 Mod，用它可以把放置在机械硬盘的超大 Mod 文件夹，直接“假装”放入 SSD 里的游戏目录中。
- 📦 **多端文件同步**：配合 OneDrive 等网盘工具，把不在同步盘里的工作文件夹，通过符号链接映射到同步盘目录内。
